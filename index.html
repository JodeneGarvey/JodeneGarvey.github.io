LET'S EAT

LET'S EAT is a food ordering system that I have developed using ASP.NET Core Web API for the backend, React JS for the frontend and SQL Server for the database. The feature of this application is user authentication where different customers can register and create an account, login into their account and they can also reset there password or email. Once they are registered they can browse the different food items and their categories that are available on the website to add to their cart. Once they are satisfied with their selection they can then place an order and have an option to either pickup or have the order delivered along with the ability to track the progress of their order. LET'S EAT also has an admin dashboard that only authorized users can access, where they can see a the amount of food items on the system, total amount of registered users, number of orders that are pending and the total sales made by LET'S EAT. The admin can also go ahead and add, delete and update food items to the menu, see a list of customers that are registered and be able to change their authorization on the system. The admin can also see all the orders and update their status in the system.

Netflix Data Analysis Project

Tools & Skills: Python, Pandas, NumPy, Plotly, TextBlob, Data Cleaning, Exploratory Data Analysis (EDA), Sentiment Analysis

This project explores the Netflix Movies and TV Shows dataset to uncover meaningful patterns in content distribution, ratings, release trends, and genres. Using Python and interactive Plotly visualizations, I analyzed how Netflix’s library has evolved over the years, which countries produce the most content, and the differences between movie and TV show releases. In addition to traditional EDA, I applied sentiment analysis with TextBlob to evaluate the tone of content descriptions, categorizing them into positive, negative, and neutral sentiment. This added a natural-language perspective to the dataset, revealing how Netflix positions its content through descriptive language. Overall, the project demonstrates strong skills in data wrangling, visualization, and NLP techniques, transforming raw data into clear and engaging insights.
